# knowledge/：运行时知识索引

为用例步骤提示词（aiAct instruction）提供**按需懒加载**的背景知识：常驻的只有本目录的轻量索引，命中触发词的步骤才读取对应正文并以 `[knowledge:<id>]` 标记追加进 instruction，交给现场 Agent 规划。未命中的步骤零开销，用例 YAML 不被修改，报告中可见增强后的完整 prompt。

## 启用（默认关闭）

```bash
KNOWLEDGE_INDEX_ENABLED=1 pnpm test:cases   # 或其他执行入口
KNOWLEDGE_INDEX_ROOT=knowledge pnpm test:cases  # 可选：自定义根目录（缺省本目录）
```

关闭（缺省）时执行行为与无本能力完全一致，不读取本目录。

## 目录约定

```
knowledge/
  index.yaml          # 索引：条目 id、触发词 triggers、正文相对路径 file
  entries/*.md        # 正文：一段简短的设备/产品操作知识
```

- `id`：稳定标识，进入注入标记 `[knowledge:<id>]`，报告据此定位命中条目。
- `triggers`：触发词数组，对 instruction 做**子串匹配**（ASCII 不区分大小写）。多条命中按索引声明顺序全部注入、同一正文不重复。
- `file`：正文文件相对本目录的路径，**不得越出**本目录；索引加载时校验存在性。

## 维护指引

- **触发词保持特异性**：过短的触发词（如“设置”）会命中大量无关步骤。优先使用完整操作名（如“控制中心”“下拉通知栏”）。
- **正文保持短小**：正文会完整进入命中步骤的模型 prompt，是“知识片段”而非文档；与操作无关的背景放别处。
- **只写操作方式（HOW）**：本机制解决“怎么做”的差异；“某产品不支持某功能”这类能力判定属于编写期问题，运行时注入无法补救。
- 索引或正文非法（缺失、不可解析、路径越界）会使命中它的步骤**显式失败**并报告条目 id 与原因；`knowledge/` 目录整体不存在则视为未配置，不报错。
- 条目当前对全部设备一致生效；按设备/平台区分条目属于后续扩展，索引结构尚未包含适用范围字段。

示例条目 `control-center-gesture` 为框架演示身份，未在任何真实设备上验证业务效果；启用前请按目标设备改写正文。
