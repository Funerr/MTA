# 视觉断言经验离线评估报告

**结论：GO**

本报告只评估有限视觉断言能否在隔离实验中复用历史证据，**不替换原生 `aiAssert`**，也不把结果解释为跨设备统计保证。

## 1. 预设 go / no-go

- 协议：`visual-assert-protocol@1`
- 误通过门槛：0（分母：humanLabel === false 的样本数（该类型/本轮））
- 每类覆盖率门槛：≥ 0.8（分母：semanticType 为 binary-control 或 explicit-text 的样本数（含人工 unknown；不含开放语义））
- 开放语义：必须全部 unknown
- 人工 unknown：不得输出 supported / contradicted
- 数据或执行错误：不得判为有效通过

## 2. 配置与数据

- 评估配置：`visual-assert-eval@1`
- 数据版本：`visual-assert-fixtures@1`
- Matcher：`visual-matcher@1`（校准后冻结，不对验证集逐例改阈值）
- OCR：关闭（未内置模型；能力不足时 unknown，禁止在线 VLM）
- 复现命令：`pnpm exec vitest run tests/unit/experience-visual-assert.test.ts`

## 3. 验证集检查

- 无数据/执行错误：通过
- 误通过为零：通过（0 / 分母 20）
- 覆盖率门槛：通过
- 开放语义 unknown：通过
- 人工 unknown 保持 unknown：通过
- 两次验证决策一致（忽略耗时）：是

## 4. 失败与困难样本

验证集无误通过/误拒绝/执行错误；困难样本（removed / other-page / 开放语义）均保留为 unknown。

## 5. 边界与后续

- 冻结集满足预设 go 条件；仅建议另开生产化 Change，不替代原生 aiAssert
- go 仅表示：可另开生产化设计 Change 讨论断言资格；**原生 aiAssert 仍是用例通过状态的判断入口**。
