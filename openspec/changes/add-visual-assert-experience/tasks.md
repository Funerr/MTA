## 1. 研究协议与数据

- [ ] 1.1 核对 Promotion/Matcher 已可复用，建立隔离实验入口与固定输出目录；验证不注册新生产 Node、不修改 aiAssert 或动作资产。
- [ ] 1.2 按设计准备两类断言的正反及 unknown 样本、人工标签和来源，先按原始捕获分组再划分校准/验证；以样本数量、冻结清单和无跨组原图变体验证。
- [ ] 1.3 记录预设 go/no-go 标准、指标分母、配置与数据摘要；检查每类覆盖率门槛、误通过零容忍和开放语义 unknown 规则均可由结果直接判断。

## 2. 离线评估

- [ ] 2.1 实现二态控件和明确文本的有限评估，输出 supported/contradicted/unknown 与理由；用状态相反、缺失、歧义和开放语义例验证，缺证据不得默认 false/true。
- [ ] 2.2 如文本评估使用 OCR，固定本地依赖和模型版本并验证离线运行；环境或能力不支持时输出 unknown，不使用在线 VLM 补标签。
- [ ] 2.3 实现逐样本结果、误通过/误拒绝/unknown/覆盖率和耗时汇总；用人工可算的小样本验证指标分母及损坏数据显式报错。

## 3. 冻结实验与结论

- [ ] 3.1 只在校准组调参，冻结后在验证组执行两次评估；验证决策/计数一致、困难样本未被删除并记录命令和完整结果。
- [ ] 3.2 产出 go/no-go 研究报告及失败案例，任何误通过或覆盖不足均为 no-go；以结论可追溯、边界明确且原生 aiAssert 完全未改变为完成依据，no-go 不要求实现生产替代。
