## Context

依赖 experience-assets 已落实。官方 API 文档确认存在结构化执行 dump 选项，但这不足以证明可完整拿到逐动作前后截图与目标关联；必须在本 Change 的首项工作中通过实际依赖的边界集成验证。

实施前置：[add-experience-model](../add-experience-model/proposal.md)。本次为提前规划，前置完成后先核对实际契约。

[Midscene API reference](https://www.midscenejs.com/reference/)（2026-09-15 核对）列出 persistExecutionDump 与报告选项；完整逐动作字段仍待锁定版本的取证试验确认。

## Goals / Non-Goals

**Goals:** 用真实证据完成自动资产生成，并将版本耦合限制在一个轨迹适配模块中。

**Non-Goals:** 不重建 Agent/Report，不读取 HTML 猜轨迹，不接管全局 aiAct，不把额外截图调用当作当时 Locate 截图。

## Decisions

### 1. 取数可行性是实施关口

优先使用锁定版本原生结构化 dump/可用公开执行数据，核对 task/action ID、成功状态、截图时序、bbox 坐标空间与实际动作参数。若缺少字段，只允许在公开截图/动作边界做局部采集包装并调用同一原生实现，不替换定位和动作执行。若两条路径都不能证明关联，记录缺口并暂停依赖此成果的后续实施，修订计划或推动上游支持；不能把采集失败伪装为闭环成功。

### 2. 适配与学习入口

增加 src/experience/trace-adapter.ts（或同职责局部文件）输出按单次 callId 隔离的规范化轨迹。Promoter 只消费该轨迹和请求上下文，不依赖报告 HTML 布局。验证入口加载实际 Midscene 包，通过隔离的框架集成夹具调用原生接口并采集轨迹，完成后调用 Promoter；设备/模型 I/O 可在公开边界受控替换，不编写手机业务流程。必须保留包版本、生成方法和来源，纯手写轨迹仅用于解析失败测试，不能证明真实接口可取数。调用边界支持未来 Runtime 在同次 Step 后发布，不能只验证进程结束时才有数据的离线通路。

### 3. 支持集和完成证据

对 Tap/Input/Scroll/LongPress/Back/Home 建立逐类型映射表；所有必需原生参数有映射才算支持，任一未知类型则整链跳过。为每动作保存 before、after、target/context 裁剪与签名；候选还保留真实 entry 和 terminal。bbox 必须绑定物理截图像素，越界/裁剪为空/缺失帧返回错误。不从 action tip 文本推断已执行成功，也不因 Node 成功直接认定全部证据完整。

### 4. 纯动作资格由项目明确登记

调用方提供已登记策略及有效请求指纹；未登记、内嵌检查、动态输出或 trace 中出现未建模行为均拒绝学习。策略明确请求不承载业务断言，并检查本次轨迹及返回结果未超出策略。独立 aiAssert 保持原生执行，Promoter 只承诺 candidate 的动作执行证据，不承诺用例业务断言已通过。

### 5. 资产加工与发布

使用固定且带版本的图像解码、裁剪和签名方案；context 的扩边比例记录在资产元数据。统一裁剪边界并验证目标图非空；签名不混淆内容校验 hash 与 matcher 相似性签名。一次调用完成所有图片后交 Store 原子发布，result 为 promoted/skipped/failed 并给原因与 callId。Store eventId 使用 callId，重复学习幂等。

### 6. 中途恢复与数据时序

只保存 AI 本次实际执行的后缀，不尝试拼接已重放的旧前缀。后缀绑定其真实入口，保留旧链失效记录；从原始入口再次调用若无可匹配完整链就重新学习。等待动画稳定只能使用真实采集到的画面；无法关联 before/after 时跳过，而非用末尾图填充。

## Risks / Trade-offs

- [原生数据不足或格式变化] → 真实轨迹兼容性报告是必交付，版本锁定与不支持拒绝覆盖。
- [模板图包含动态信息导致后续不可靠] → 保存完整原图供 matcher 显式处理，不提前删除目标状态信息。
- [学习成功误当业务成功] → candidate 与最终用例 verdict 分开，原生断言仍决定业务结果。

## Migration Plan

先用离线失败/完整夹具验证，再用实际 Midscene 集成夹具生成的轨迹发布 candidate 并重新加载验证完整性；单列受控边界与真实设备验证范围，不要求业务用例交付。回滚只移除采集接入，原生执行继续可用，保留已发布资产和来源。
