# project-init Specification (Delta)

## Purpose

为框架使用方提供一条命令的初始化入口：检测 Node 与 pnpm 前提、安装依赖、生成 `.env` 脚手架并输出环境预检报告与下一步指引，把多步手工上手链路收敛为可重复执行的单命令，同时保持"不替用户安装、不替用户选择"的显式边界。

## ADDED Requirements

### Requirement: Node 版本前提检测

初始化脚本 SHALL 在执行任何安装动作前检测当前 Node 版本是否满足仓库 `engines.node` 约束；不满足时 MUST 以非零退出码结束，输出当前版本、约束内容与升级指引，且 MUST NOT 替用户安装或切换 Node 版本。

#### Scenario: Node 版本满足约束

- **WHEN** 以满足 `^20.19.0 || ^22.12.0 || >=24.0.0` 的 Node 运行初始化脚本
- **THEN** 版本检测通过，脚本继续执行后续步骤

#### Scenario: Node 版本不满足约束

- **WHEN** 以不满足约束的 Node（如 18.x）运行初始化脚本
- **THEN** 脚本以非零退出码结束，输出中包含当前版本、约束说明与升级指引，且未执行任何安装动作

### Requirement: pnpm 可用性检测

初始化脚本 SHALL 检测 pnpm 是否可在当前环境调用；不可用时 MUST 以非零退出码结束并给出安装指引（如 corepack 启用或全局安装），且 MUST NOT 替用户安装 pnpm。

#### Scenario: pnpm 可用

- **WHEN** 环境中 `pnpm --version` 可正常调用
- **THEN** 检测通过，脚本继续执行依赖安装

#### Scenario: pnpm 缺失

- **WHEN** 环境中无法调用 pnpm
- **THEN** 脚本以非零退出码结束，输出包含可执行的安装指引，且未替用户执行任何安装命令

### Requirement: 依赖安装

前提检测通过后，初始化脚本 SHALL 执行仓库既有的依赖安装命令并继承其 postinstall 行为；安装失败时 MUST 以非零退出码结束并保留原始错误输出，不得静默吞掉或重试掩盖。

#### Scenario: 依赖安装成功

- **WHEN** 前提检测通过且依赖安装命令成功退出
- **THEN** 脚本继续执行 `.env` 脚手架与环境预检

#### Scenario: 依赖安装失败

- **WHEN** 依赖安装命令以错误退出（如网络不可达）
- **THEN** 脚本以非零退出码结束，错误输出中保留安装命令的原始失败信息

### Requirement: .env 脚手架

初始化脚本 SHALL 在 `.env` 不存在时从 `.env.example` 复制生成，并提示使用者填写模型四项配置；`.env` 已存在时 MUST NOT 覆盖或修改其任何内容。

#### Scenario: 首次运行生成 .env

- **WHEN** 仓库根目录不存在 `.env` 文件
- **THEN** 脚本从 `.env.example` 复制生成 `.env`，并在输出中提示需填写的模型配置项

#### Scenario: .env 已存在时保持不动

- **WHEN** 仓库根目录已存在 `.env` 文件（无论是否已填写）
- **THEN** 脚本不覆盖、不修改该文件，输出中说明已跳过

### Requirement: 环境预检报告

依赖安装与 `.env` 脚手架完成后，初始化脚本 SHALL 输出一张预检报告，至少覆盖：模型四项配置是否非空、`adb` 与 `hdc` 是否可调用及各自枚举到的设备标识（0 台、1 台或多台均显式列出）。预检 SHALL 只报告结果，MUST NOT 因模型配置为空、工具缺失或设备数量（含零台与多台）而判定初始化失败，也 MUST NOT 替用户选择设备或写回任何配置。

#### Scenario: 全部就绪

- **WHEN** `.env` 模型四项均已填写且 adb 恰好枚举到一台已授权设备
- **THEN** 预检报告逐项标注通过状态并列出该设备标识

#### Scenario: 模型配置缺失

- **WHEN** `.env` 中模型四项存在空值
- **THEN** 预检报告标注具体空缺项，并指向 `.env.example` 内的模型配置说明，脚本仍正常结束

#### Scenario: 多台设备在线

- **WHEN** adb 枚举到两台及以上设备
- **THEN** 预检报告列出全部设备标识并说明需通过环境变量显式指定，不替用户选择

#### Scenario: 平台工具缺失

- **WHEN** 本机未安装 hdc（或 adb）
- **THEN** 预检报告将该工具标注为不可用及对应影响，脚本仍正常结束

### Requirement: 下一步指引

初始化脚本成功结束前 SHALL 输出最小后续步骤指引，至少包含：填写 `.env` 模型配置、将用例 YAML 放入 `cases/level*/` 目录、以既有 `test:cases:*` 入口执行，使使用者无需查阅其他文档即可知道下一动作。

#### Scenario: 成功结束时输出指引

- **WHEN** 初始化脚本各步骤成功完成
- **THEN** 输出中包含指向 `.env` 填写、用例目录与执行命令的下一步指引

### Requirement: 可重复执行

初始化脚本 SHALL 支持安全重复执行：再次运行时 MUST NOT 覆盖已存在的 `.env`，依赖安装按既有包管理器语义增量执行，不产生破坏性副作用。

#### Scenario: 二次运行

- **WHEN** 初始化成功后再一次运行同一脚本
- **THEN** 脚本正常完成，`.env` 内容保持不变，已安装依赖不发生破坏性重装

### Requirement: 离线初始化

除包管理器自身的依赖下载外，初始化脚本 MUST NOT 发起任何模型调用或需要 API key 的网络请求；在模型配置完全为空的环境中 SHALL 能完整运行至预检报告与指引输出。

#### Scenario: 无模型配置的完整运行

- **WHEN** 在 `.env` 模型四项全空的环境中运行初始化脚本
- **THEN** 脚本不发起模型调用，完整执行至预检报告并正常结束
